# Cyber Detective

## About
A React-based interactive trainer for identifying cybersecurity
threats using the STRIDE threat-modeling framework.

## Features
- Interactive system architecture
- Clickable components and data flows
- Threat identification
- STRIDE classification
- Score tracking
- Progress saved in localStorage
- Final results screen

## Technologies
- React
- Vite
- Tailwind CSS
- JavaScript
- JSON

## Running the project

npm install
npm run dev

## Building

npm run build
